# Implement Approved Design

1. Read the approved design brief.
2. Identify the domain components required.
3. Reuse existing tokens and primitives before inventing new abstractions.
4. Keep interactive behavior isolated to client components.
5. Preserve the exact composition and hierarchy of the approved direction.
6. Verify with the visual-qa workflow.
7. Record any implementation compromise that changes the intended design.
