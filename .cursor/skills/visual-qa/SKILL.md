# Visual QA

Use Playwright against the local app.

Check:
- desktop wide and standard laptop
- mobile portrait
- long and short event titles
- missing/slow media
- keyboard navigation and visible focus
- reduced-motion preference
- page overflow and clipped content
- layout shifts and obvious loading issues
- heading hierarchy and image alternative text

Return evidence and severity. Do not invent screenshots or claim a pass without opening the rendered page.
