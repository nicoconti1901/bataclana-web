# Design Exploration

Use this skill when a new visual concept or major page is being designed.

## Workflow
1. Inspect current tokens, fonts, layout conventions and reference assets.
2. Define the intended emotional effect in one sentence.
3. Produce 3 materially different directions.
4. For each direction specify: navigation concept, hero composition, type hierarchy, image treatment, grid rhythm, color balance, interaction model and mobile behavior.
5. Implement each direction as an isolated route or state under a design-lab area.
6. Use browser screenshots to compare them.
7. Stop before consolidating the winner unless the user explicitly selects a direction.

Never make three near-identical variations.
