# Content Editorial

Use when creating historical, cultural, contemporary-tango or people-focused editorial sections.

Priorities:
- strong narrative hook
- useful context
- clear sourcing requirements when factual claims are introduced
- varied reading rhythms
- pull quotes, timelines, media and side-notes where appropriate
- no filler copy

Demo content must be clearly fictional or placeholder content. Real factual claims about tango history or current institutions should be researched before publication.
